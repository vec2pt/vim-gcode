# vim-gcode

G-code syntax highlighting for Vim. Plugin automatically applies syntax highlighting to files with the `.gcode` and `.ngc` extensions.

## Installation

Using [vim-plug](https://github.com/junegunn/vim-plug) and Vim:

```vim
Plug 'https://github.com/vec2pt/vim-gcode'
```

Using vim.pack and Neovim 0.12+:

```lua
vim.pack.add("https://github.com/vec2pt/vim-gcode")
```
